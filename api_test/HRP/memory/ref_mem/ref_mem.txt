１．仕様ベースのブラックボックステスト

■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1.1. エラー条件のテストケース
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
(H-a) 非タスクコンテキストから呼び出して，E_CTXエラーが返ること．
      ［NGKI3955］

(H-b) pk_rmemが指すメモリ領域への書込みアクセスが許可されていない
      場合，E_MACVエラーが返ること．［NGKI3958］

(H-c) addrが指すメモリ領域が，メモリオブジェクトに含まれていない（対応
      するメモリオブジェクト初期化ブロックの属性がTA_NOEXS）場合，
      E_NOEXSエラーが返ること．［NGKI3956］
      ※TA_NOEXS領域の番地はターゲット依存（ZYBO zybo_z7_gcc では
        メモリオブジェクト外の番地）であり，かつ prb_mem テストでも
        E_NOEXS は対象外（target依存番地の不確定性）であるため，本
        テストシートでもテストケースは設けない（refer_memory の
        TA_NOEXS 分岐は未到達）．

(H-d) addrが指すメモリ領域を含むメモリオブジェクトに対する参照操作が
      許可されていない場合，E_OACVエラーが返ること．［NGKI3957］

      (H-d-1) 対象メモリオブジェクトがカーネルドメインに
              所属している場合．

      (H-d-2) 対象メモリオブジェクトが異なるユーザドメインに
              所属している場合．

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1.2. 正常条件のテストケース
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
(H-e) addrが指すメモリ領域を含むメモリオブジェクトに対する参照操作が
      許可されている場合，E_OKが返ること．［NGKI3954］

      (H-e-1) 実行中の保護ドメインがユーザドメインで，対象メモリ
              オブジェクトに対する参照アクセスが許可されている場合．

      (H-e-2) 実行中の保護ドメインがカーネルドメインの場合．
