１．仕様ベースのブラックボックステスト

■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1.1. エラー条件のテストケース
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
(H-a) 非タスクコンテキストから呼び出して，E_CTXエラーが返ること．

(H-b) tskidが不正の時にE_IDが返ること．

      (H-b-1) tskidが許容される最小値-1(=-1)の時にE_IDが返ること．

      (H-b-2) tskidが許容される最大値+1(TNUM_TSKID+1)の時にE_IDが返ること．

(H-c) パラメータエラーの時，E_PARが返ること．

      (H-c-1) sizeが不正(=0)．

      (H-c-2) pmmodeが不正(TPM_WRITE，TPM_READ，TPM_EXEC以外の値を指定)．

(H-d) 対象オブジェクトに対する参照操作が許可されていない場合，
      E_OACVエラーが返ること．

      (H-d-1) 対象メモリ領域を含むメモリオブジェクトに対する参照操作が
              許可されていない．

              (H-d-1-1) 対象メモリオブジェクトがカーネルドメインに
                        所属している場合．

              (H-d-1-2) 対象メモリオブジェクトが異なるユーザドメインに
                        所属している場合．

      (H-d-2) tskidで指定したタスクに対する参照操作が許可されていない．

              (H-d-2-1) 対象タスクがカーネルドメインに
                        所属している場合．

              (H-d-2-2) 対象タスクが異なるユーザドメインに
                        所属している場合．

(H-e) 対象メモリ領域がメモリオブジェクトの境界を越えている場合，
      E_OBJエラーが返ること．

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1.2. 正常条件のテストケース
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【備考】
prb_memの引数で指定するメモリ領域の組み合わせ網羅はメモリ保護のテスト
で実現する．正常系テストはメモリ保護テストで実施するため，正常条件の
テストケースはなし．
正常条件では，E_OKもしくはE_MACVが返る．
