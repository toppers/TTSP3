0. API仕様

■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■

sns_ter		タスク終了禁止状態の参照〔TI〕【NGKI3494】

【C言語API】
	bool_t state = sns_ter()

【パラメータ】
	なし

【リターンパラメータ】
	bool_t		state		タスク終了禁止状態

【機能】

実行状態のタスク（タスクコンテキストから呼び出した場合には自タスク）の
タスク終了禁止フラグを参照する．具体的な振舞いは以下の通り．

実行状態のタスクが，タスク終了禁止状態の場合にtrue，タスク終了許可状態
の場合にfalseが返る【NGKI3495】．sns_terを非タスクコンテキストから呼び
出した場合で，実行状態のタスクがない場合には，trueが返る【NGKI3496】．

マルチプロセッサ対応カーネルにおいては，サービスコールを呼び出した処理
単位を実行しているプロセッサにおいて実行状態のタスクのタスク終了禁止フ
ラグを参照する【NGKI3497】．

【補足説明】

sns_terをタスクコンテキストから呼び出した場合，実行状態のタスクは自タス
クに一致する．

【TOPPERS/SSP3カーネルにおける規定】

SSP3カーネルでは，sns_terをサポートしない【SSPS0154】．

【μITRON4.0仕様，TOPPERS新世代カーネル統合仕様との関係】

μITRON4.0仕様，TOPPERS新世代カーネル統合仕様に定義されていないサービス
コールである．

(F-a) タスクコンテキストから呼出す場合．【NGKI3495】【NGKI3497】

      (F-a-1) 他プロセッサがタスク終了許可状態で，自プロセッサがタスク
              終了禁止状態で呼び出す場合，trueが返ること．
              (ASP:a-1，EX_CARE_STATE)

      (F-a-2) 他プロセッサがタスク終了禁止状態で，自プロセッサがタスク
              終了許可状態で呼び出す場合，falseが返ること．
              (ASP:a-2，EX_CARE_STATE)

(F-b) 非タスクコンテキストから呼び出す場合．

      (F-b-1) 他プロセッサがタスク終了許可状態で，自プロセッサがタスク
              終了禁止状態で呼び出す場合，trueが返ること．
              (ASP:b-1，EX_CARE_STATE)【NGKI3495】【NGKI3497】

      (F-b-2) 他プロセッサがタスク終了禁止状態で，自プロセッサがタスク
              終了許可状態で呼び出す場合，falseが返ること．
              (ASP:b-2，EX_CARE_STATE)【NGKI3495】【NGKI3497】

      (F-b-3) 非タスクコンテキストから呼び出した場合で，他プロセッサに
              タスク終了許可状態で実行状態のタスクが存在する場合に，自
              プロセッサに実行状態のタスクが存在しない場合，trueが返る
              こと．(ASP:b-3，EX_CARE_STATE)【NGKI3496】
