0. API仕様

■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■

get_nth		指定した優先順位のタスクIDの参照〔T〕【NGKI3641】

【C言語API】
	ER ercd = get_nth(PRI tskpri, uint_t nth, ID *p_tskid)

【パラメータ】
	PRI			tskpri		参照対象の優先度（対象優先度）
	uint_n		nth			参照対象の優先順位
	ID *		p_tskid		タスクIDを入れるメモリ領域へのポインタ

【リターンパラメータ】
	ER			ercd		正常終了（E_OK）またはエラーコード
	ID			tskid		タスクID

【エラーコード】
	E_CTX		コンテキストエラー
				・非タスクコンテキストからの呼出し【NGKI3642】
				・CPUロック状態からの呼出し【NGKI3643】
	E_PAR		パラメータエラー
				・tskpriが有効範囲外【NGKI3644】
	E_MACV		メモリアクセス違反
				・p_tskidが指すメモリ領域への書込みアクセスが許可されて
				　いない〔P〕【NGKI3645】
	E_OACV		オブジェクトアクセス違反
				・自タスクが属する保護ドメインに対する参照操作が許可
				　されていない〔P〕【NGKI3768】

【機能】

tskpriで指定した優先度（対象優先度）を持つ実行できる状態のタスクの中で，
nthで指定した優先順位のタスクのID番号を参照する．具体的な振舞いは以下の
通り．

対象優先度を持つ実行できる状態のタスクの中で，優先順位が(nth＋1)番目に
高いタスクのID番号が，p_tskidが指すメモリ領域に返される【NGKI3647】．優
先順位が(nth＋1)番目に高いタスクがない，言い換えると，対象優先度を持つ
実行できる状態のタスクの数がnth以下の場合には，TSK_NONE（＝0）が返され
る【NGKI3648】．

保護機能とマルチプロセッサのいずれかまたは両方に対応するカーネルでは，
自タスクと同じスケジューリング単位に属するタスクのみを操作対象とする
【NGKI5127】．

tskpriにTPRI_SELF（＝0）を指定すると，自タスクのベース優先度が対象優先
度となる【NGKI3650】．

【TOPPERS/SSP3カーネルにおける規定】

SSP3カーネルでは，get_nthをサポートしない【SSPS0159】．

【μITRON4.0仕様，TOPPERS新世代カーネル統合仕様との関係】

μITRON4.0仕様，TOPPERS新世代カーネル統合仕様に定義されていないサービス
コールである．

(F-b) tskpriでTPRI_SELF（＝0）を指定し，自タスクとは別のスケジューリン
      グ単位（他プロセッサ）に自タスクのベース優先度と同じ優先度を持っ

      に返される．【NGKI3647】【NGKI3650】【NGKI5127】

      (F-b-1) 自プロセッサの実行できる状態のタスクが自タスクのみの場合．

              (F-b-1-1) nthに0を指定し，他プロセッサの実行できる状態の
                        タスクが1つである場合，自プロセッサの優先順位
                        が1番目に高いタスクIDが返ること．
                        (ASP:c-1-1，EX_CARE_STATE)

              (F-b-1-2) nthに1を指定し，他プロセッサの実行できる状態の
                        タスクが2つである場合，TSK_NONEが返ること．
                        (ASP:c-1-2，EX_CARE_STATE)【NGKI3648】

              (F-b-1-3) nthに2を指定し，他プロセッサの実行できる状態の
                        タスクが3つである場合，TSK_NONEが返ること．
                        (ASP:c-1-3，EX_CARE_STATE)【NGKI3648】

      (F-b-2) 自プロセッサの実行できる状態のタスクが2つである場合，

              (F-b-2-1) nthに0を指定し，他プロセッサの実行できる状態の
                        タスクが1つである場合，自プロセッサの優先順位が
                        1番目に高いタスクIDが返ること．
                        (ASP:c-2-1，EX_CARE_STATE)

              (F-b-2-2) nthに1を指定し，他プロセッサの実行できる状態の
                        タスクが2つである場合，自プロセッサの優先順位が
                        2番目に高いタスクIDが返ること．
                        (ASP:c-2-2，EX_CARE_STATE)

              (F-b-2-3) nthに2を指定し，他プロセッサの実行できる状態の

                        (ASP:c-2-3，EX_CARE_STATE)【NGKI3648】

      にtskpriで指定した優先度を持った実行できる状態のタスクがある場合，
      自プロセッサに属する実行できる状態のタスクの中で，優先順位が
      (nth＋1)番目に高いタスクのID番号をp_tskidが指すメモリ領域に返すこ
      と．【NGKI3647】【NGKI5127】

      (F-c-1) 自プロセッサの実行できる状態のタスクがない場合．

              (F-c-1-1) nthに0を指定し，他プロセッサの実行できる状態の

                        (ASP:d-1-1，EX_CARE_STATE)【NGKI3648】

      (F-c-2) 自プロセッサの実行できる状態のタスクが1つである場合．

              (F-c-2-1) nthに0を指定し，他プロセッサの実行できる状態の
