このドキュメントの位置付け
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
このドキュメントは，TTGおよびTTCのソースコードカバレッジを取得する方法
をまとめたものである．TTGのカバレッジ取得には，APIテストで作成した
TESRYデータを使用し，TTCのカバレッジ取得には，TTCテスト用に作成した
TESRYを使用する．なお，動作環境はCygwinを想定している．

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
環境構築手順
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
----------------------------------------------------------------------
[1]rubygemsインストール
----------------------------------------------------------------------
rubygemsとは，Rubyの標準パッケージ管理システムであり，後述のカバレッジ
取得用ライブラリであるrcovをインストールするのに必要である．

(1)rubygems-1.6.2.tgzを任意のディレクトリへ展開する．
   "rubygems-1.6.2"というディレクトリが作成される．

(2)setup.rbを実行する
   $ ruby setup.rb

※rubygems公開サイト
  http://rubyforge.org/projects/rubygems/

----------------------------------------------------------------------
[2]rcovインストール
----------------------------------------------------------------------
rcovとは，Rubyプログラム実行時のソースコードカバレッジをhtml形式で生成
するライブラリである．

(1)rubygemsによりrcovをインストールする．(インターネット接続が必要)
   $ gem install rcov

----------------------------------------------------------------------
[3]rubyライブラリの修正
----------------------------------------------------------------------
rcovが利用するrubyライブラリのrexmlには，既知のバグがある．
/lib/ruby/1.8/rexml/formatters/pretty.rb の127行目のwrapメソッドを以下
のように修正する．

----------------------------------------------------------------------
def wrap(string, width)
  # Recursively wrap string at width.
  return string if string.length <= width
  place = string.rindex(' ', width) # Position in string with last ' ' before cutoff

  return string if place.nil?  # この行を追加

  return string[0,place] + "\n" + wrap(string[place+1..-1], width)
end
----------------------------------------------------------------------

カバレッジ取得手順
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
TTGおよびTTCのカバレッジ取得に必要なコマンドは，ttg_rcov.shにまとめてい
るため，ttg_rcov.shを実行することで，カレントディレクトリに"coverage"デ
ィレクトリが作成され，その中のindex.htmlにてカバレッジを確認できる．

# ttg_rcov.sh

参考情報
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
ttg_coverage.rbにて使用している単体テストライブラリに関しては，以下を参
考にする．

1. 単体テストプログラムを作成
単体テストライブラリTest::Unitを利用
http://www.ruby-lang.org/ja/man/html/Test_Unit.html

ex. Calc.rb (テスト対象クラス)
----------------------------------------------------------------------
class Calc
  def sum(val1, val2)
    return val1 + val2
  end

  def foo(val, flg)
    if (flg == true)
      return val * 2
    else
      return val / 2
    end
  end
end
----------------------------------------------------------------------

ex. test.rb (単体テストプログラム)
----------------------------------------------------------------------
require "test/unit"
require "Calc.rb"

class CalcTest < Test::Unit::TestCase
  def setup()
    @obj = Calc.new()
  end

  def test_sum()
    assert_equal(3, @obj.sum(1, 2))
  end

  def test_foo()
    assert_equal(2, @obj.foo(1, true))
  end
end
----------------------------------------------------------------------

test.rbを実行すると単体テストの結果が得られる．

2. rcovで実行
$ rcov test.rb

オプション例
-x PATTERN      PATTERNにマッチするファイルをカバレッジ結果生成対象から除外
-i PATTERN      PATTERNにマッチするファイルをカバレッジ結果生成対象に加える
--charset CODE  生成するHTMLの文字コードを指定
