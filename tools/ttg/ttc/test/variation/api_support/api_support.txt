このドキュメントの位置付け
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
このドキュメントは，ターゲットによってはサポートしていないAPIに関する対
応が，TTC(TOPPERS Test checker)で要件通り正しく行われていることを確認す
るためのテスト仕様書である．

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
APIのサポートに関する要件
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
以下の3つがターゲットによってはサポートしていないAPIである(以下，対象
APIと呼ぶ)
・get_utm
・ena_int
・dis_int

(要件1)
configure.yamlで以下のパラメータ(以下，対象パラメータと呼ぶ)に対して
falseが指定された場合，TESRYデータのvariation属性である対象パラメータに
trueが指定された対象APIを用いているテストケースはテスト対象外とされるこ
と．また，テスト対象外とされたテストケースがあった場合に，実行結果とし
て【備考】に示した情報が表示されること．
・api_support_get_utm : get_utmに対するパラメータ
・api_support_ena_int : ena_intに対するパラメータ
・api_support_dis_int : dis_intに対するパラメータ

(要件2)
configure.yamlで対象パラメータに対してtrueが指定された場合，TESRYデータ
のvariation属性である対象パラメータにtrueが指定された対象APIを用いてい
るテストケースでもテスト対象とされること．

【備考】
・実行結果として表示される情報
  ・入力されたテストケースの総数
  ・実行可能であったテストケースの数
  ・NGテストケースとして除外されたテストケースの数
  ・NGテストケースとして除外されたテストケースのテストIDと除外理由(英語)
  ・総数と除外した数から，実行可能であったテストケースの割合(％)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
要件に対する確認内容
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
テストに用いたTESRYデータは，ttsp/api_test/配下にある全TESRYデータであ
る．
全TESRYデータの内，get_utmを用いているTESRYデータは4件，ena_intを用いて
いるTESRYデータは8件，dis_intを用いているTESRYデータは8件である．

----------------------------------------------------------------------
(要件1)に対する確認 - get_utm
----------------------------------------------------------------------
【実施内容】
・configure.yamlのapi_support_get_utmに対してfalseを指定
 (もしくはTTG実行の際に，オプション"--api_support_get_utm false"を指定)
・ttsp/api_test/配下にある全TESRYデータを引数に指定してTTG実行

【確認内容】
・TTGにより生成されたソースコードに，get_utmを用いているテストケースが
  除外されていることを確認した
・要件の【備考】に記載された各項目が出力されていることを確認した
 (NGテストケースとして除外されたテストケースのテストIDと除外理由は，除
  外されたテストケースのファイルパスが出力されるttg_exclusion_list.txt
  に記載されているファイルパスによって確認した)

【実施内容】
・configure.yamlの対象パラメータに対してtrueを指定
 (もしくはTTG実行の際に，オプション"--api_support_get_utm true

  含まれていることを確認した
